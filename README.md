# 💗 Carta para Marinela

Página web interactiva creada como una carta digital.

## Cómo usarla

Abre `index.html` en cualquier navegador.

## Publicarla en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`.
3. Ve a **Settings → Pages**.
4. Selecciona la rama `main` y la carpeta `/root`.
5. Guarda y espera a que GitHub publique la página.

No necesita servidor ni base de datos.
